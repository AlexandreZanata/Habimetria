# Brand Assets

Source vectors for the Habimetria identity. Rules and palette live in
[brand-identity.md](../brand-identity.md).

- [habimetria-mark.svg](habimetria-mark.svg) — isolated geometric H, pinho on transparent.
- [habimetria-icon.svg](habimetria-icon.svg) — app icon: Marfim mark on a pinho rounded square.
- [habimetria-logo.svg](habimetria-logo.svg) — horizontal lockup, mark plus `habimetria` wordmark.

Do not edit these files for one-off screens. Reuse the app brand
component and the design-system tokens instead.
