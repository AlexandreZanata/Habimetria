# Paywall — Hosted Services Only

Superseded commercial direction: charging R$29.90 per Tenancy/seal,
watermarking local PDF previews and capping local Evidence for payment.
Those are no longer approved requirements.

The binding contract is [service monetization](service_monetization.md):
all on-device functionality is free; hosted services use admin-priced
monthly subscriptions purchased through the relevant mobile store.
The former number is historical context, never a default retail price.

Place the subscription offer at the chosen hosted action. Never block
capture, local seal, local PDF, local verification, local comparison,
local assistant or file export. Subscription explanations must distinguish
local durability from optional cloud preservation.

The current backend still contains the old PaymentPort seam. Its removal
and cloud-boundary replacement are implementation steps, not effects of
this documentation change. See [payments](../03-architecture/payments.md).
