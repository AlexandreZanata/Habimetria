# Paywall — Sell Protection, Not PDF

## Rule

Free until value is created. Pay to seal and protect.

## Free

- Create property
- Run inspection
- Up to N evidences (e.g. 20)
- Report preview (watermarked, no QR)

## Paid — R$29,90 / tenancy (tune after measurement)

- Seal inspection
- Immutable originals storage
- Verifiable report + QR + public verify page
- Share link + access log
- Occurrences timeline
- Future exit compare

Copy: **"Protect this tenancy for R$29,90"**, not "Pay to download PDF".

## Anti-abuse

- Cap: e.g. 300 photos, 30 short videos, 2 GB per tenancy.
- Photo-first. Video: 15–30s max, only for motion proof.
- Payment provider behind `PaymentPort` interface (Stripe/MercadoPago).
