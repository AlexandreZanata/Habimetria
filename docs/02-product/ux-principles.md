# UX Principles — Absurdly Simple

1. One question per screen. One action per screen.
2. Camera-first. No form before first photo.
3. No signup before value (5–10 min invested first).
4. Auth = magic link, no password.
5. Upload truth: `saved locally | uploading | confirmed ✓ | retry !`
6. Never claim "registered" before server ack.
7. Timeline per property: entry → inspection → occurrences → exit.
8. Sharing creates evidence: created / accessed / downloaded logs.
9. Legal honesty: "shared" ≠ "agreed". Show disclaimer in UI and PDF.
