# Usability Sessions — Five First-Time Users (U12 Protocol)

Unexecuted: no session has run; this protocol is ready for the device
pass. Small qualitative gate, not a population claim. Use synthetic
Property data only: no keys, real addresses, real-user location or photos.

## Setup

Release build on the reference device, API stopped, network blocked.
Seed two synthetic Properties: one with a DRAFT inspection in progress,
one with history (SEALED inspection + finalized Report). No navigation
coaching; the facilitator answers questions with "o que você tentaria?"
and never touches the device.

## Tasks (per participant)

1. Resume the draft and add one room photo with a finding note.
2. Switch Property and reach the sealed inspection's review.
3. Find the finalized Report, open it and reach verification.
4. Remove the empty Property (cancel first, then confirm).
5. Archive the Property with history, find it under Arquivados, restore it.

## Record per task

Completion (unaided / aided / gave up), tap count, time, help requests,
and any confusion between deletion and archive. Targets: at least four
of five unaided completions per task; zero unintended deletions; zero
misunderstandings that archive deletes photos. Any data loss, false
confirmation or inaccessible primary action blocks release regardless
of the counts.

## Report back

Append a dated section to the [acceptance report](acceptance-report.md)
with device/OS/build, per-participant rows, confusion quotes and defects
filed. Attach screen recordings (with consent) and the filled matrix to
the release evidence.
