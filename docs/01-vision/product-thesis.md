# Product Thesis — Habimetria

## Decision

We do not build inspection software. We build **rental evidence preservation software**.

User goal, months later: **"It was already like this when I moved in, and I can prove it."**

## Core loop

```text
Capture → Seal → Share → Compare
```

Entry:

```text
New property → rooms → guided capture → findings → review → local seal → PDF → share
```

Exit:

```text
Open property → exit inspection → repeat photos → entry × exit compare → final report
```

## Positioning

- Tenant-side tool. Agency is recipient, not operator.
- "Seal" is terminal. Originals immutable after seal.
- Feels like a **digital safe**, not a bureaucratic form.
- Home headline: **"Don't pay for what you didn't break."**
- CTA: **"Protect my tenancy"**

## Commercial boundary

The complete on-device journey is free. Optional hosted preservation,
synchronization and collaboration use admin-priced monthly subscriptions.
See [service monetization](../02-product/service_monetization.md).

## Trust triad (brandable)

1. Guided inspection
2. Evidence vault
3. Verifiable report
